# Breast Cancer Prediction using Machine Learning

This project predicts whether a tumor is malignant or benign using Machine Learning. A Logistic Regression model was trained on the Breast Cancer dataset and achieved **97% accuracy**.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Features

* Data preprocessing
* Data visualization
* Model training
* Model evaluation

## Model Performance

* Algorithm: Logistic Regression
* Accuracy: 97%

## Future Improvements

* Random Forest and SVM implementation
* Hyperparameter tuning
* Web app deployment using Streamlit
